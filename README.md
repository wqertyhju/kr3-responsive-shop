# Kr3 Responsive Shop

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание проекта

Адаптивная версия многостраничного HTML/CSS-сайта учебного интернет-магазина. Проект основан на структуре КР №1 и не использует CSS-фреймворки: адаптивность реализована вручную через медиазапросы, Flexbox и Grid.

## Подход к адаптивности

- Mobile First: базовые стили рассчитаны на мобильный экран, расширения добавляются через min-width;
- медиазапросы: @media (min-width: 768px) и @media (min-width: 1024px);
- css/responsive.css подключён после css/style.css на всех страницах;
- проверен корректный viewport на всех 5 страницах;
- контейнеры: width: min(100% - 32px, 1200px);
- адаптивные отступы через clamp();
- изображения: max-width: 100%, height: auto, loading="lazy", picture + srcset;
- таблица характеристик обёрнута в .table-wrapper с горизонтальной прокруткой.

## Адаптивные решения

- шапка: static на мобильном, sticky с 768px;
- навигация: колонка на мобильном, строка с 768px;
- hero-блок: одна колонка → две колонки с 768px;
- сетка карточек: 1 → 2 колонки с 768px → 3 колонки с 1024px;
- каталог: одна колонка → 260px + 1fr с 768px;
- форма заявки: одна колонка → две колонки с 768px;
- таблица: горизонтальная прокрутка на узких экранах;
- изображения: picture с srcset, loading="lazy", адаптивные размеры.

## Исправления по доступности

- у всех полей формы есть label;
- у изображений осмысленный alt;
- семантическая структура (header, nav, main, section, article, aside, footer);
- корректные заголовки страниц и разделов;
- размер интерактивных элементов не меньше 44px;
- проверка фокуса при навигации с клавиатуры.

## Как проверить

1. Открыть index.html — проверить hero-блок, преимущества, сетку карточек.
2. Открыть catalog.html — проверить фильтр и сетку товаров.
3. Открыть product.html — проверить picture, таблицу характеристик.
4. Открыть order.html — проверить форму.
5. Открыть contacts.html — проверить контакты.
6. Сузить окно до 360px, 768px, 1024px — проверить перестройку блоков.
7. Открыть DevTools → Console — убедиться в отсутствии ошибок.
